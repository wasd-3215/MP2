# 低上下文成本错题诊断索引

自动分析全部798道验证题，模型只需判断的题有355道；三个代表预测器的错题去重后为79道，其中38道共同错、41道体现互补。

第一批只导出8张分层抽取的短证据卡：题目、官方答案、四个解析答案、各方法选择，以及一个错误候选和一个正确候选的截断文本。因果原因均标为UNREVIEWED。

## 阅读流程

1. question_index.csv用于本地筛选与统计，不需要整份送入模型。
2. 每次只读取review_cards.jsonl中的2–4张卡，优先识别可观察错误；无法判断时，按source_file/source_line回看相应候选全文。
3. 保留reason、evidence、confidence和needs_more_context四项标注；没有证据时留待复核，不能把统计标签当作推理错误。
4. 每批只保留结构化标注与新增模式摘要，避免在对话里重复粘贴历史推理。
5. 根据模式是否重复，再扩大抽样；频率统计仍以完整索引为准，分层8张卡不代表总体发生率。

## 自动标签与人工原因分开

共同失败、方法互补、错误最高票、单例答案组、解析失败与同结构C/P纠错方向可由预测及官方标签直接得到。条件遗漏、单位错误、算术错误、参考答案歧义等必须人工审阅文本，不能由程序直接认定。

全部题目加候选文本共1,705,184字符；第一批题目与证据片段共8,978字符，减少约99.5%。这是字符量比较，不是精确token测量，实际还包括少量JSON元数据。

本轮只做自动索引和待审证据整理，没有重新训练、预测、评分或完成全量人工错因诊断。训练规则或学习参数不能由验证人工标签直接拟合；后续方法应在训练数据上建立并冻结后评价。

源数据、预测与评分原样保留；所有输出只用于研究诊断，不可作为部署查表。未读取测试集语义内容，原文件保护扫描仅按字节核对。
